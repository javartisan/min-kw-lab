# 知识图谱 · 七大方向学习脚本

对应 `docs/index.html` 的学习体系。每个文件夹 = 一个技术方向；每个脚本 = 一个学习小点。

```text
src/
├── 01_知识表示/   Ontology · RDF/OWL · Embedding
├── 02_知识获取/   NLP流水线 · NER · RE · EE
├── 03_知识存储/   图数据库 · Neo4j/Cypher · RDF存储
├── 04_知识推理/   规则推理 · 本体推理 · Embedding推理
├── 05_知识融合/   实体对齐 · 本体匹配 · 冲突消解
├── 06_知识问答/   KBQA · 语义解析 · GraphRAG
└── 07_知识分析/   图分析 · 指标洞察 · 可视化分析
```

## 怎么学

1. 先读 `docs/` 对应笔记，再跑脚本。
2. 脚本均为 **纯 Python 标准库**（无需安装 Neo4j / spaCy），可直接运行：

```bash
python3 src/01_知识表示/01_ontology.py
```

3. 建议按编号顺序：建图谱（1→5）再学用图谱（6→7）。

## 设计约定

- 示例统一用证券领域（茅台、股票代码、行业、控股等）。
- 注释偏多：讲「为什么」而不只写「怎么做」。
- 图库相关脚本用**内存图**模拟，便于本地跑通；Cypher/SPARQL 以字符串演示真实写法。
