知识图谱中的本体（Ontology）· 四个构件
本体＝领域共享概念模型的显式说明，在知识图谱中承担「模式层」角色，约束数据层实例
模式层 · TBox（本体定义的概念骨架）
① 类 Class / 概念 Concept
同类实体的抽象归纳，支持 is-a 层级
例：人物 ⊃ 员工 ⊃ 工程师
② 关系 Relation
类与类、实例与实例之间的语义连接（动词）
例：任职于、位于、part-of、kind-of
③ 属性 Property
类/实例的特征描述，分两类：
数据属性：姓名、年龄 · 对象属性：就职公司
实例化 instantiate —— 概念与规则落到具体数据
数据层 · ABox（本体在数据中的落地）
④ 实例 Instance / Individual
类的具体成员，是知识图谱中的实体节点
例：张三（"人物"类的实例）、字节跳动（"公司"类的实例）
四构件如何协同 —— 一个迷你知识图谱片段
张三 (人物类实例) —任职于→ 字节跳动 (公司类实例) 年龄 = 30 (数据属性)
类/关系/属性定义属于 TBox（模式层）；实例属于 ABox（数据层）——合起来构成完整知识库 KB。
