知识分析 · 精炼学习笔记

目标：快速抓住图分析 / 指标洞察 / 可视化分析的核心，能说清「图谱不止能查，还能挖结构和趋势」。

一句话总览

知识分析 = 在知识图谱上做统计、结构挖掘与业务洞察，把「关联数据」变成「可决策结论」。

要点 本质 输出
图分析 中心性、路径、社区、相似性 关键节点、团伙、桥接人
指标洞察 基于图的业务 KPI / OLAP 行业分布、关系密度、事件统计
可视化分析 交互探索与叙事展示 子图、下钻、报告视图 
干净图谱（存储+融合）
  → 图算法 / 聚合查询
  → 指标与结构发现
  → 可视化 / 报告 / 风控策略

与问答的差别：问答偏「一问一答」；分析偏「批量挖掘、指标监控、探索式发现」。

在七大方向中的位置：建图与对齐之后的增值层；常与问答共用同一张图。

1. 图分析（Graph Analytics）

核心定义

利用图的拓扑结构做计算：谁重要、谁成团、两点如何连通、结构是否异常。

必知几类算法（直觉级）

类型 问什么 证券直觉
中心性 谁是枢纽？ 关联公司最多、处在控股网核心的主体
路径 A 到 B 怎么连？ 股权穿透、关联交易路径
社区发现 谁经常抱团？ 产业链集群、隐式关联集团
相似度 谁和谁结构像？ 竞品候选、对标公司
异常/环 有无奇怪回路？ 异常持股环、数据质量问题

最小 Cypher 分析例子

// 一度关联最多的公司（简易「度中心性」）
MATCH (c:Company)-[r]-(n)
WHERE c.entityType = 'Company'
RETURN c.name AS company, count(r) AS degree
ORDER BY degree DESC
LIMIT 10

// 两公司之间是否存在竞争或共同行业
MATCH (a:Company {name:$a}), (b:Company {name:$b})
OPTIONAL MATCH (a)-[:COMPETES_WITH]-(b)
OPTIONAL MATCH (a)-[:BELONGS_TO]->(i:Industry)<-[:BELONGS_TO]-(b)
RETURN a.name, b.name,
       exists((a)-[:COMPETES_WITH]-(b)) AS competes,
       collect(DISTINCT i.name) AS sharedIndustries

// 股权穿透示意（深度 1..3）
MATCH path = (a:Company {name:$name})-[:CONTROLS|HOLDS_SHARE*1..3]->(b)
RETURN path
LIMIT 50

Neo4j GDS（Graph Data Science）库提供 PageRank、Louvain 等；入门先用 Cypher 聚合与路径即可。

分析结果如何回写

常见做法：把分数写成节点属性（pagerank、communityId），供问答与前端过滤——分析产出也可变成图谱知识。

速记

  • 图分析回答：「结构上谁重要、谁一伙、怎么连」
  • 先路径与度数，再上专业图算法库

2. 指标洞察（Metrics / OLAP on KG）

核心定义

把业务问题定义成可计算指标，在图谱上聚合、切片、对比与监控。

证券 KG 常见指标

指标 计算直觉
实体规模 公司/股票/事件数量（本项目 getStats）
关系密度 边数 / 可能边数；平均度数
行业覆盖 各 Industry 下公司数分布
文档贡献 每篇 Document 的 MENTIONS 数
事件热度 近一段 Event 数量与涉及公司
图谱完整度 有代码但无行业、有公司无高管的比例（质量）

与传统数仓的关系

数仓/宽表 图谱指标
擅长 固定报表、强 SQL 聚合 多跳关联后再聚合
互补 金额、行情时间序列 股权链、关联方、事件网络

实务：行情与财务进数仓，关系与事件进图谱，分析层可JOIN两者。

本项目已有萌芽

GET /api/stats → entities / relations / documents / byType
这是最简「指标洞察」。可演进为：按行业分布、按关系类型直方图、质量缺口清单。

速记

  • 指标洞察回答：「用数字概括图谱健康度与业务结构」
  • 好指标 = 可复算 + 可下钻到子图证据

3. 可视化分析（Visual Analytics）

核心定义

通过交互可视化支持人探索、验证、讲述图谱结论；不是「把图画画好看」而已，而是分析闭环的一部分。

常用视图

视图 用途
力导向全图/子图 发现团块与桥接
以实体为中心的邻域 公司画像（一度/二度）
路径高亮 解释「如何关联」
时间线 + 事件 定增/并购叙事
矩阵/桑基 行业—公司、持股流向（进阶）

分析交互闭环

看概览指标 → 点进异常行业/高度数节点
  → 展开邻域 → 发现可疑路径
  → 固化为结论/规则/问答模板

本项目对应

能力 落点
力导向图 frontend/src/GraphCanvas.tsx
检索过滤 前端关键词 → /api/graph?q=
节点详情 选中节点展示属性
待增强 社区着色、路径查询 UI、指标仪表盘

速记

  • 可视化分析回答：「让人眼完成算法不好定义的发现」
  • 原则：概览先、下钻后、结论可回到查询复现

问答 vs 分析（对照）

维度 知识问答 知识分析
触发 一个自然语言问题 批量任务 / 探索 / 定时报表
输出 答案 + 证据 指标、排名、社区、报告
用户 业务问询者 分析师 / 风控 / 数据同学

二者常联动：分析发现「高度数关联方」→ 沉淀为问答模板「谁是关联最多的公司」。

②识别枢纽公司或关联密集主体
③否则数字不可审计

⑤stats + 力导向探索

建议学习顺序

  1. 用 Cypher 写清：规模、分布、度数 TopN、简单路径
  2. 把结果画到现有前端或 Browser
  3. 定义 5 个证券业务指标（含质量缺口）
  4. 需要社区/PageRank 时再引入 GDS
  5. 与问答打通：高频分析结论 → 问答模板
