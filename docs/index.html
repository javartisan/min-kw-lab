1. 知识表示

定义概念、关系及其形式化表达方式。

要点 说明
Ontology 本体：约定领域内的概念、属性与关系体系（含 TBox 模式层 / ABox 数据层）
RDF/OWL 语义网标准：用三元组与本体语言描述知识；推理时「TBox 公理 × ABox 事实」
Embedding 嵌入表示：将实体与关系映射到连续向量空间

精炼笔记 → 1、知识表示-精炼学习笔记.md

2. 知识获取

从非结构化/半结构化数据中抽取知识。

要点 说明
NLP 抽取 基于自然语言处理的知识抽取流水线
NER Named Entity Recognition，命名实体识别
RE Relation Extraction，关系抽取
EE Event Extraction，事件抽取

精炼笔记 → 2、知识获取-精炼学习笔记.md

3. 知识存储

持久化与查询知识图谱。

要点 说明
图数据库 以图模型存储节点与边，适合关联查询
Neo4j 主流属性图数据库（Bolt / Cypher）
RDF 以 RDF 三元组库形式存储语义数据

精炼笔记 → 3、知识存储-精炼学习笔记.md

4. 知识推理

由已有知识推导隐含事实。

要点 说明
规则推理 基于逻辑规则、产生式规则推导新知识
本体推理 基于本体公理（传递、包含、互斥等）推理
Embedding 基于向量表示做链接预测、补全与推理

精炼笔记 → 4、知识推理-精炼学习笔记.md

5. 知识融合

整合多源知识，消除冗余与冲突。

要点 说明
实体对齐 识别并合并指向同一现实对象的不同实体
本体匹配 在不同本体/模式之间建立概念对应关系
冲突消解 对矛盾信息做取舍、置信度加权或人工裁决

精炼笔记 → 5、知识融合-精炼学习笔记.md

6. 知识问答

面向自然语言的图谱问答与证据返回。

要点 说明
KBQA 以知识图谱为真相来源的问答
语义解析 自然语言 → Cypher / SPARQL
GraphRAG 检索子图作上下文再生成答复

精炼笔记 → 6、知识问答-精炼学习笔记.md

7. 知识分析

在图谱上做结构挖掘、指标统计与可视化洞察。

要点 说明
图分析 中心性、路径、社区、结构相似性
指标洞察 规模、分布、质量与业务 KPI
可视化分析 交互探索、下钻与叙事展示

精炼笔记 → 7、知识分析-精炼学习笔记.md
